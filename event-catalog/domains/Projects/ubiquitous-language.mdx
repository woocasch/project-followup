---
dictionary:
  - id: Project
    name: Project
    summary: "Long running project that has to be followed over a period of time."
    icon: Wand2
    description: |
      A project is an entity that represents some process to be done in real life.

      This may be anything, but is rather intended to be a long running process. So baking a cake would be hard to represent correctly as a project. Planning a tour during vacation could be. Building a house (together with planning stage) would probably be even better.

      Projects may have multiple tasks to be performed with user assignable to each of them. Task may be commented and have a due date (or don't have one).

      You can have a meeting to follow-up on progress of tasks.

  - id: Task
    name: Task
    summary: A part of project that has well defined completion conditions.
    icon: Wand2
    description: |
      A task is something required for the project to be completed.

      It should be something that you can without much doubt verify as being completed. It should also be something that has to be done by one or more persons who are assigned to it.

      During tasks lifetime you can add comments about progress, problems or other remarks that provide wider context required for understanding what's needed for task to be completed.
