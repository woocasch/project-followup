## Architecture diagram

<NodeGraph />

### What is this?
Write only database of events representing changes of domain state.

### What does it store?
- **Projects information**: Information about projects being followed.
- **Tasks information**: Information about tasks being added as part of projects.
- **Users assignment**: Assignment of users to tasks and projects.

### Who writes to it?
- **ProjectsService** is the owner of the database and is the only one able to write it.

### Who reads from it?
- **ProjectsService** has a background worker that reads data from the writes model and materializes it to read model in **ProjectsReadsModel**.
